Citing: CRIMSON: A Clinically-Grounded LLM-Based Metric for Generative Radiology Report Evaluation

Towards Better Aligned LLM Judges for Radiology Report Evaluation across Modalities and Anatomies

Federica Bologna, Jean-Philippe Corbeil, M. Wilkens, Asma Ben Abacha · 2026

What they say: CRIMSON is grouped with RadFact, GREEN, FineRadScore, and CLEAR as an LLM-based metric that assesses the clinical factuality of a generated radiology report against a reference using an error-detection-centered schema, and it is also cited as an example of distilling LLM annotations into a small fine-tuned model. It is used as one of four prior-work baselines (alongside RadFact, GREEN, and FineRadScore) against which the paper's zero-shot VERT prompt is compared on the expert-annotated RadEval and RaTE-Eval datasets in Table 1.

  • Prior works such as RadFact (Bannur et al., 2024), GREEN (Ostmeier et al., 2024), FineRad-Score (Huang et al., 2024), CLEAR (Jiang et al., 2025), and CRIMSON (Baharoon et al., 2026) use LLMs to assess the clinical factuality of a radiology report against a reference report using different schemas.
  • The evaluation of radiology reports has largely followed two separate lines: fine-tuning small models on LLM-generated labels and designing LLM-based metrics centered on error detection (Huang et al., 2024; Ostmeier et al., 2024; Zam-brano Chaves et al., 2025; Baharoon et al., 2026).
  • We also compare it against established base-lines: RadFact (Bannur et al., 2024), GREEN (Ost-meier et al., 2024), GREEN-EC (sum of error counts), FineRadScore (Huang et al., 2024), and CRIMSON (Baharoon et al., 2026).
